# One Place One Result (OPOR)

OPOR ist ein schulisches Softwareprojekt zur Berechnung von Noten.  
Ziel ist es, Noten übersichtlich, nachvollziehbar und stressfrei darzustellen.

Das Projekt wurde von Schülern der Oberstufe (Q2 und Q4) am Gymnasium Steglitz entwickelt.

---

## Projektstruktur
- [(https://github.com/SASSYwarner/Notenrechner-OPOR/index.html)](https://github.com/SASSYwarner/Notenrechner-OPOR/blob/main/index.html) ist das HTML der Website.
- Der Notenrechner ist als eigene Datei umgesetzt und direkt in die Webseite eingebettet.
  Dadurch können Änderungen an der Berechnungslogik einfach und ohne großen Aufwand vorgenommen werden.
- ## Rechner-Struktur
- 
- [rechner-calc.html](https://github.com/SASSYwarner/Notenrechner-OPOR/blob/main/Website/Rechner/rechner-calc.html)  
  Enthält den eigentlichen Rechner, samt Funtion und Tabelle
